# 《ethan-hold 开源宣发作战清单》

## 用法说明
这份清单贴墙用！别把它当成泛泛而读的理论汇报。它是我们工位推项目的实操手册，每天干完一项用红笔打勾，卡住的时候对照排查。

- **先看什么**：先看阶段一（战前整备）的 🔴 必做项。代码没有完全跑通、单文件 HTML 离线看板还没经过断网验证前，绝对不要对外发任何物料；
- **后看什么**：物料就绪后，按照阶段二、三、四的节奏推进，严格按照 🟡 看懂套用 里面的模版剪视频、排图文、挂置顶评论；
- **卡住回看**：
  - 如果离线看板在别人电脑上白屏或者图表错位，**卡住回看 DEV-01**（零依赖单文件检查）；
  - 如果测试数据穿透出来的结果对不上真实持仓，**卡住回看 DEV-02**（25只基金基准测试集核验）；
  - 如果视频发出去播放量平平或者评论区没人互动，**卡住回看 OPS-02**（黄金前3秒扎心反常识剪辑与评论区痛点截流）；
  - 如果遭遇竞品抄袭或者代码被搬运，**卡住回看 BRD-01**（首发时间戳固化与 Ethan Family 家族生态护城河）。

## 阶段一：战前整备（T-7 ~ T-3）

### 1. 🔴 必做/核心突破：【零依赖离线 HTML 看板压力测试】
- 【**讲啥**】：彻底揪出所有潜藏的外网 CDN、远程字体和第三方 JS 库依赖。确保生成的 HTML 资产看板在完全断网（断开 Wi-Fi、拔掉网线）状态下，无论是用 Safari、Chrome 还是手机浏览器本地直接双击打开，所有原生 SVG 图表、悬停穿透交互、熔断警报横幅都能秒级丝滑渲染。绝不能因为 CDN 被墙或者本地环境缺少依赖导致白屏，否则尝鲜用户的体验会瞬间归零。
- 【**重点拿**】：`templates/dashboard_template.html` 内联原生 SVG 矢量图表与纯内联 CSS/JS 渲染引擎，保证生成的 `dashboard.html` 体积在 50KB 左右，零网络请求。
- 【**怎么用**】：断网测试：生成一次 `dashboard.html`，关闭网络，在两台不同操作系统的电脑上直接双击打开，检查鼠标悬停个股穿透、板块树状图展开以及 🔴 P0 熔断警报动画是否全部正常交互。

### 2. 🔴 必做/核心突破：【25只真实特征基金基准测试集核验】
- 【**讲啥**】：核验标准测试数据集，必须真实复现“25只公募基金、8只因限购并联买入的纳指 100 基金、泛科技与半导体高集中度重仓（合并敞口达 65.56%）、组合整体浮亏 -13.00%”这一组典型基民痛点样本。凭啥能打动用户？就凭这套数据跟成千上万天天盯盘、越亏越想补仓的真实基民持仓一模一样，真实才有穿透力。
- 【**重点拿**】：`tests/fixtures/portfolio_25_funds.json`，验证穿透加权合并算法能把 NVDA、AAPL、MSFT、中芯国际等底层同质化持仓精准归集，并触发 🔴 P0 单行业超限（>45%）及 🟠 P1 逆势浮亏加仓熔断规则。
- 【**怎么用**】：终端执行 `python scripts/run_analysis.py --data tests/fixtures/portfolio_25_funds.json`，核验控制台输出与看板页面数据一致，必须明确弹出“触发 48 小时强制冷静期”的拦截警示。

### 3. 🔴 必做/核心突破：【仓库发布前防抄袭封闭准备】
- 【**讲啥**】：在正式首发前，GitHub 仓库严格保持 Private（私有）状态，严防半成品被爬虫或国内二创营销号逆向洗稿抄袭。完成工业级 README、CONTRIBUTING 指南、MIT 开源许可证以及投资免责声明的最终封版，确保一旦切 Public，第一时间具备权威首发时间戳与完整版权溯源。
- 【**重点拿**】：完整的 GitHub 仓库物料包（包含中英双语 README、Issue 模板、PR 模板、MIT LICENSE 及免责声明）。
- 【**怎么用**】：在本地完整克隆一份干净仓库，模拟外部开发者执行 `git clone` 并按照 README 快速上手指南一步步运行，确认无报错无漏传文件，静候首发日一键切公网。

### 4. 🟡 看懂套用：【终端彩色穿透与高保真看板动图制作】
- 【**讲啥**】：贴墙用！自媒体时代没人有耐心读通篇文字，README 首屏和自媒体物料必须有 3 秒看懂的高清动图。录制一段终端敲下命令、彩色 ASCII 进度条飞速计算并合并同类项的录屏；再录制一段在 HTML 看板上鼠标悬停穿透、查看英伟达实际占比近 15% 的动态交互。
- 【**重点拿**】：`assets/terminal_demo.gif`（终端 5 秒穿透实录）与 `assets/dashboard_preview.png`（看板深色高颜值截图）。
- 【**怎么用**】：用终端录屏工具（如 VHS 或 asciinema）生成极客范 GIF，大小压缩在 4MB 以内，直接嵌入 README 首屏 Hero 区域与自媒体首发物料包。

### 5. 🔵 了解/略读：【冷启动社群与工位同事小范围盲测】
- 【**讲啥**】：私信发给 3~5 位平时喜欢定投、手里买了一堆基金但经常被套的工位同事或铁杆技术粉丝，不提供任何说明书，只发测试持仓和脚本，看他们能不能双击搞定。
- 【**重点拿**】：收集他们看到自己穿透结果时的第一反应口头禅（比如：“我靠，我怎么买了这么多英伟达？！”、“原来我天天买的半导体加纳指全是同一帮人在炒！”），直接提炼成视频脚本的黄金文案。
- 【**怎么用**】：将他们遇到的困惑记录下来，补充到 README 的常见问题 FAQ 和后续评论区预置答疑库中。

## 阶段二：潜伏发酵（T-3 ~ T-1）

### 6. 🔴 必做/核心突破：【核心爆款视频分镜打磨与抗压剪辑】
- 【**讲啥**】：坚决砍掉一切“哈喽大家好我是某某”的无效废话！视频前 3 秒必须直奔主题——镜头直怼浮亏 -13% 的真金白银惨烈账单，制造“我以为买了 25 只基金是科学分散，其实底层全在给两家美股巨头打工”的认知冲突。实操环节演示终端 1 秒穿透和红黑相间的硬顶熔断警报，把工具的极客气质拉满。
- 【**重点拿**】：B站与微信视频号 6 分钟 4 栏标准视频成片（画面、台词、音效、屏幕文字），导出 1080P 60fps 高清母带。
- 【**怎么用**】：对照分镜脚本逐帧检查，必须做到第 8 秒抛出痛点、第 25 秒讲清买菜三轮车鸡蛋比喻、第 110 秒弹出 HTML 单文件看板、第 180 秒触发大红熔断拦截。

### 7. 🟡 看懂套用：【小红书“扎心大字报”5图轮播排版套用】
- 【**讲啥**】：小红书受众注重视觉反差与情绪共鸣。套用既定的 5 图大字报排版模版，把绿油油的持仓截图、穿透前后的惊人对比、硬顶熔断大红弹窗做成高颜值信息流卡片。
- 【**重点拿**】：5 张 3:4 比例竖版图文素材：
  - P1（封面）：红黑大字报《以为分散配置，实则单只裸奔？！》
  - P2（扎心账单）：25 只基金亏损清单，高亮并联买入的 8 只纳指；
  - P3（穿透真相）：掀开底裤，NVDA + AAPL 真实权重暴露暴击图；
  - P4（硬顶刹车）：防冲动买入硬顶熔断器界面（强制冷静期 48 小时）；
  - P5（怎么白嫖）：极速上手指南，本地单文件无云端泄露。
- 【**怎么用**】：直接套用小红书文案模版发布，标题突出“7只QDII穿透实测”，文末留出“在评论区报出基金代码，我帮大家免费测同质化”的互动钩子。

### 8. 🔵 了解/略读：【各平台合规外链与暗号路径设计】
- 【**讲啥**】：各主流自媒体平台（尤其是小红书和微信生态）对直接发 GitHub 外部链接审查极严，稍有不慎就会被降权甚至吞评论。必须提前打通合规引流闭环，确保流量顺畅沉淀。
- 【**重点拿**】：小红书主页置顶图文引导话术、微信视频号扩展链接、B站评论区直链白名单格式。
- 【**怎么用**】：小红书统一使用“开源代码与看板自取指路主页置顶”或评论区回复“开源”触发关键词；B站直接在首条置顶评论放置规范的完整 GitHub URL。

## 阶段三：全域引爆（D-Day T0 首发日）

### 9. 🔴 必做/核心突破：【GitHub 仓库切 Public 与首批 Star 冲刺】
- 【**讲啥**】：首发日上午 10:00 准时将仓库切换为 Public 状态，正式发布 Release v0.1.0 标签。GitHub 的 Trending（趋势榜）算法对首发 6~12 小时内的 Star 增速与 Fork 活跃度权重极高，必须在视频发布的第一时间，把高意向开发者和种子用户直接灌入仓库。
- 【**重点拿**】：仓库 Release v0.1.0 发版说明、GitHub Trending 实时监控页面、种子群同步消息模版。
- 【**怎么用**】：仓库公开后，第一时间在技术社群、开发者朋友圈发布诚恳的开源宣告，号召前排基友点亮 Star，确保首日突破 100+ Star 冲入 Python 榜单视野。

### 10. 🔴 必做/核心突破：【全网多平台同频齐发 + 置顶评论截流】
- 【**讲啥**】：上午 11:30（午休前黄金流量高峰），B站、视频号、小红书全网多平台同时上线核心视频与图文。视频发布后 5 分钟内，必须迅速完成官方置顶评论的布设，把观众被视频点燃的情绪在第一时间转化为克隆代码和点 Star 的实际行动。
- 【**重点拿**】：精心打磨的置顶评论模版（包含开源直达链接、两行命令离线体验方法、绝对本地运行隐私保证、以及“报代码免费测穿透”的互动话题）。
- 【**怎么用**】：视频发出立刻置顶，动员前排种子读者在 15 分钟内点赞顶评，稳稳霸占评论区首屏第一位。

### 11. 🟡 看懂套用：【评论区实时互动与反常识答疑 SOP】
- 【**讲啥**】：评论区是建立个人专业品牌口碑的核心战场。面对“基金季报滞后穿透有用吗”、“大盘下跌工具能治亏损吗”、“为什么不做成小程序非要跑命令行”等典型质疑，严禁用公关套话辩解，必须像工位同事一样用大白话比喻和专业逻辑务实拆解。
- 【**重点拿**】：预置的 4 套高情商实战回复话术（安全带比喻、80%核心暴露逻辑、财产隐私绝对本地化底线、打包exe路线图）。
- 【**怎么用**】：首发当天安排专人每隔 30 分钟刷新评论区，遇到提问迅速翻牌，用专业友善的互动拉高动态权重。

### 12. 🔵 了解/略读：【海外极客平台 Show HN / Reddit 提交备选】
- 【**讲啥**】：当国内全网势能爆发后，将英文版的 README 与演示动图整理为标准的 Show HN 格式，同步发布至 Hacker News 以及 Reddit 的 r/Python、r/investing 板块，获取海外开源社区的长尾关注。
- 【**重点拿**】：`Show HN: ethan-hold – Penetrate pseudo-diversified mutual funds and circuit-break panic buying (100% offline HTML)`。
- 【**怎么用**】：选在美东时间早晨（北京时间晚上 21:00 左右）提交，顺带测试海外开发者对单文件本地无云端看板的兴趣度。
