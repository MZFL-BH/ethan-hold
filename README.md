## 一、产品设计哲学：6 大产品创新思路重塑

很多金融记账软件做着做着就变成了满屏复杂报表的传统 Excel。`ethan-hold` 拒绝平庸，在立项之初就深度融入了 **6 大产品创新推演方法论**，完成了从工具到“个人风控门神”的系统性重塑：

### 1. 竞品负向拆解法（“去差评区里捡黄金”）
- **行业真相**：对标天天基金、蚂蚁财富、雪球等大厂理财 APP，千万别学它们做对了什么，而是看它们被骂得最惨的是什么。大厂为了照顾几亿大众和赚取申购赎回手续费，功能越来越臃肿，满屏的直播带货、加仓榜单，刺激用户高频买入。去应用商店差评区一扒全是泪：“根本看不清买了啥、越跌越买被套死、一跌起来所有基金全军覆没”。大厂靠手续费吃饭，对防冲动熔断这种“断自己财路”的痛点看得见却嫌肉少不肯改。
- **我们的切入点 (Unbundling 功能单拆)**：从对标产品身上单拆出两个核心功能——**“底层资产穿透合并”**与**“拥有否决权的交易前硬顶熔断”**，只解决散户最痛的“假分散”与“冲动追跌”，做得比大厂轻 10 倍、快 5 倍、真诚 100 倍。

### 2. 孙正义“时光机”理论（机构风控跨市场降维移植）
- **行业真相**：在一个市场已经厮杀成红海的成熟玩法，搬到一个信息差市场，往往是降维打击。成熟家族办公室（Family Office）、主权基金和量化对冲机构有年费几十万的彭博 PORT、MSCI Barra 风险因子模型和交易前合规拦截闸口（Pre-Trade Compliance Gate），任何一笔下单前必须穿透到底层股票算敞口；而普通散户在券商 APP 上只能看到几张互不相干的代码卡片，任由情绪支配。
- **我们的切入点**：把机构级的“多基金底层穿透加权矩阵相乘”与“三级硬顶熔断引擎”，跨市场降维移植给普通散户与极客基民，用轻量 Python 脚本与单文件 HTML 仪表盘打破大厂的信息壁垒。

### 3. 工作流摩擦力消除法（“数用户切了几次软件”）
- **行业真相**：最刚需的产品不是发明了新概念，而是消灭了用户反复切换软件的痛苦。基民原来想搞清真实敞口，一共要切 5 个软件：看天天基金查收益 ➡️ 抄支付宝看持仓 ➡️ 打开 Excel 手动敲代码和金额 ➡️ 打开 Choice 查每只基金的季报持仓 ➡️ 拿计算器反复算英伟达加总占了多少。这里面一共切了 5 个软件、复制粘贴了几十次。
- **我们的切入点**：在这个链条里“连消带打”，帮他把中间所有动作合并成“点一下搞定”。输入 JSON / CSV / Markdown，甚至直接贴入一段文字，本地引擎 0.2 秒完成清洗规范化、穿透相乘、行业归集、熔断拦截校验、生成零外链单文件离线看板。

### 4. 观察“民间的土办法”（铺平并联限购那条泥泞小路）
- **行业真相**：伟大的产品往往不是凭空发明的，而是看到很多人在用一种极其别扭的“笨办法”凑合。因为美股 QDII 经常被外汇额度卡脖子（单日限额 100 元/500 元），民间基民自创了极其别扭的“笨办法”：同时定投广发纳指、万家纳指、华安纳指、南方纳指等 6~8 只影子基金，再用 Excel 复杂的宏或小红书记账打卡硬凑。
- **我们的切入点**：把民间拼凑版方案做成一个干净独立的系统化单点工具。内置并联同质化集群识别引擎（`detect_clone_groups`）与同质冗余指数（RI），自动揪出影子基金并给出规模费率最优的瘦身归集方案。

### 5. 技术代差重构（“用现代 AI 与原生轻量重写老行业”）
- **行业真相**：过去 10 年金融分析软件全是笨重的 Windows 客户端、死板的规则引擎，少个逗号就报错崩溃。如果组合风控软件是今年才被发明的，结合现在的 AI 语义理解与轻量级 Python/SVG，它原本该长成什么样？
- **我们的切入点**：它应该具备强大的自然语言容错（中英文符号、会计负数括号、全角半角逗号通吃）、无代码自适应运行，坚持 100% 离线隐私计算（Zero-CDN），单文件 HTML 纯原生 SVG 矢量渲染，拔掉网线双击秒开。

### 6. 垂直极端人群切入法（“服务那 5% 的硬核重度基民”）
- **行业真相**：通用产品满足 80 分大众，垂直人群愿意为 95 分掏大钱。市面上不缺花里胡哨的普通记账软件，缺的是专门给那 5%“手里握着 10~30 只 QDII/科技/半导体、浮亏深度超 -10%、手痒总想越跌越买摊薄成本”的极客投资者准备的保命罗盘。
- **我们的切入点**：懂他们的硬核语言（QDII 限额、英伟达 Blackwell 算力周期、48 小时冷冻期、戴维斯双杀），提供买入前 What-If 互动沙盒与四大主力重仓（黄金、纳指、红利低波、固收+）的宏观知识背景与波动预测，成为他们下单前必须过一遍的“风控门神”。

## 三、核心特性

- 🔍 **底层标的同质化穿透合并**  
  采用矩阵加权求和算法 $W_k = \sum (w_i \times h_{i,k})$，跨越基金公司与市场壁垒，将多只基金中重复持有的股票归并加总。内置 Jaccard 与余弦相似度算法，自动抓取因限购而并联买入的“影子基金”。
- 🛑 **拥有否决权的三级硬顶熔断风控引擎**  
  - **🔴 P0 一级硬顶熔断 (CRITICAL)**：宏观泛科技敞口 $\ge 50\%$、单一细分赛道 $\ge 35\%$、单一底层个股 $\ge 15\%$ 时直接硬顶阻断，拒绝任何买入建议。
  - **🟠 P1 逆势追跌防冲动冷冻 (WARNING)**：拟买入科技标的浮亏超过 $-10\%$ 时，坚决拦截“摊薄成本”冲动，强制启动 **48 小时冷静期倒计时**。
  - **🟢 健康再平衡放行 (APPROVED)**：加仓纯债、现金、黄金等防守资产，成功被动稀释泛科技高风险敞口，准予执行。
- 📊 **清爽亮色系单文件零依赖离线 HTML 看板 (Light Mode)**  
  **100% 离线自包含（Zero-CDN / Offline-First）**。底色采用清爽浅灰 `#f6f8fa` 与纯白卡片 `#ffffff`，高对比度文字，严禁大面积压抑深黑，适合自媒体展示与日常查阅。纯原生 SVG 绘制视网膜图表，拔掉网线双击秒开。
- ⚡ **交互式买入前模拟试算器 (Pre-Trade Simulator)**  
  在真正掏钱买入之前，输入拟买入基金代码与金额，前端 JS 与后端 Python 规则完全对齐，动态推演加仓后的各项风险敞口，事前拦截可能突破硬顶的操作。
- 🛡️ **绝对本地隐私第一 (Local First)**  
  持仓数据是个人最核心的财务隐私。本工具不搞账号体系、不发网络请求、不做后台埋点，所有运算都在你本地芯片上完成。

### 1. 建信上海金 ETF 联接 C (001000) · 占比 24.13%

- **🔮 未来 1~3 个月潜在波动与风险预测**：短期金价已逼近历史 95% 超买分位数高位。若美国抗通胀数据反复推迟降息，或地缘局部停火，面临阶段性 **5%~10% 的高位剧烈震荡回调与多头踩踏**；需防范人民币汇率对境内金价的汇兑侵蚀。
- **💡 投资实操应对建议**：
  - **严禁追高加仓**：24.1% 占比已达组合第一大重仓防守极限量；
  - **倒金字塔阶梯止盈**：若金价继续冲高致占比超 28%，每上涨 5% 赎回 20% 的浮盈份额，再平衡至红利或纯债；底仓 20% 坚定锁死作为极端黑天鹅对冲盾牌。

## 九、工业级防幻觉指南：手机长截图自适应切片 (Tile Slicing) 与标准 Prompt 模板

### 1. 为什么长图直接喂给大模型必崩？
手机长截图（滚动截屏）长宽比通常达 1:8 ~ 1:12（例如 `1170 × 11520` 像素）。在上传到 ChatGPT、Claude、WorkBuddy 或 Antigravity 时，前端组件会自动将其等比缩放至 `104 × 1024` 像素。
- **物理事实**：一整行 15 个汉字被挤在 104 像素内，每个字仅占 3×3 = 9 个像素点；
- **致命后果**：偏旁与笔画严重粘连，大模型在 9 个像素前根本看不清字，只能结合前后上下文“脑补猜词”，将上下两行拼合成不存在的幻觉基金（如将“财通成长优选”与“融通稳信增益”拼成“财通稳进增益”）。

### 2. 解决方案：内置自适应切片器 (`scripts/slice_image.py`)
本项目内置了自适应垂直滑窗切片器。长图输入时自动切割为 2~5 张黄金视口图片，并附带 15% 垂直冗余重叠带：
```bash
python3 scripts/slice_image.py --input your_screenshot.jpg --output-dir ./slices/
```

### 3. 开箱即用：喂给 GitHub 用户 / 大模型的防幻觉 System Prompt 模板
当你在 WorkBuddy、Cursor、ChatGPT 或 Claude 中使用本项目，或者指导第三方大模型处理基金截图时，**直接复制以下 Prompt 喂给大模型**：

```markdown
【任务设定与输入门禁】：
你是一个专业的资深基金资产配置与仓位罗盘专家（ethan-hold）。当用户向你提供基金持仓截图或数据时，必须严格执行以下防幻觉三步走：

【第一步：图片分辨率与切片前置检测】
1. 严禁直接阅读未经切片的高长宽比滚动长图（长宽比 > 2.0 时会因前端等比压缩丢失汉字笔画导致严重幻觉）；
2. 若环境支持运行 Python 脚本，优先执行：`python3 scripts/slice_image.py -i <image_path>` 将其垂直切成 2~4 张高清分块图再逐张识别；
3. 若无脚本环境，必须提醒用户：“为避免超长截图压缩失真，请截取 2~3 张局部单屏截图上传”。

【第二步：提取与 6 位纯数字代码反查】
1. 识别图片时，必须以基金的【6 位纯数字代码】为第一优先级准绳，杜绝仅靠模糊文字拼凑；
2. 提取出 6 位代码后，从公募基金官方字典反查全称（如识别到 012525 必须精准对齐为“融通稳信增益 6 个月持有期混合 C”，绝不捏造）；
3. 对分块重叠区域中重复出现的基金代码进行行级去重。

【第三步：执行三级硬顶与加仓沙盒研判】
1. 识别并归集并联影子基金（如 6 只纳指 100 联接）；
2. 测算泛科技真实穿透敞口（是否突破 50% 硬顶）；
3. 任何自身浮亏 <= -10.0% 的标的拟加仓时，一律拍红牌触发 P1 逆势追跌防冲动冷冻，启动 48 小时冷静期；
4. 输出清爽明亮浅底色系（Light Mode）的分析结果与定投发车清单。
```
